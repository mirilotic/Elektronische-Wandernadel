# Elektronische Wandernadel

von mirilotic



Version 1.0 vom 23.09.2026



Programm zum Eintragen und Ansehen von bisherigen Erfolgen bei der Harzer Wandernadel.



Einträge können geändert und gelöscht (in Arbeit) werden, die ganze Tabelle kann bei Bedarf auch gelöscht werden.



Zusätzlich gibt es noch ein Zimmer, in welchem die bisher erwanderten Abzeichen dargestellt werden, sowie eine kleine Statistik.



Viel Spaß!



Aktuell geplante Anpassungen / Neuerungen:



* Änderung der Fensternamen in der Projektmappe in aussagekräftigere Namen
* Möglichkeit, einzelne Zeilen in der Tabelle herauszulöschen
* Funktionale Änderung beim Löschen der Tabelle
* Verschönerung der Urkunde in den Zimmerbildern
